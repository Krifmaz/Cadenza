System input

Cadenza as the system's upsampler: cadenza serve --system sink adds an output device "Cadenza" that any app (or the whole desktop) can play to; --system app:<name> takes one application's sound before the mixer. Or [system] in the config. Linux: PipeWire (build feature pipewire). Windows 10 2004+: process loopback (feature loopback); there sink means all apps except Cadenza, as Windows has no virtual device without a signed driver. macOS 14.2+: process taps (feature tap), muted, so sink takes all apps but Cadenza and they are heard only through it.

Filter designer

Pick a transition width, stopband depth, cutoff, window and phase; Cadenza works out the length (it grows with the ratio, so the filter has the same shape in Hz at every output rate), designs it in 64-bit and caches it. Top: the response up to twice the source Nyquist (peak level per point, so no sidelobe hides between points). Left: the passband ripple. Right: the impulse around its peak. Filters over 2M taps at the chosen rate are not plotted.

Loopback verification

Connect the DAC's output (or a digital output) back to the input chosen under Room correction, turn the volume to 100 %, and run. The bit-perfect check plays a random 24-bit pattern with the engine in bit-perfect mode and looks for it, sample for sample, in the recording – only a digital loopback can pass. THD+N plays a 997 Hz tone through the chain as configured; through an analog loopback it measures the DAC and the ADC together.

Room correction

Put a measurement microphone at the listening seat. Each measurement plays a sine sweep from one speaker (turn the volume down first). The correction is a minimum-phase FIR that only cuts peaks and fills dips up to the set limits, then loads as the convolution filter.
